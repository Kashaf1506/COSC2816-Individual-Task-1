# Raw dataset placement

Raw datasets are not tracked by Git.

## Dataset 1: Predict Students' Dropout and Academic Success

Place `data.csv` in:

`data/raw/dropout/data.csv`

Source: https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success

## Dataset 2: Open University Learning Analytics Dataset

Place the extracted OULAD files in:

`data/raw/oulad/`

Source: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
